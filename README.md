# Órbita: Fronteira — entrega do projeto

Baixe `orbita-fronteira-mvp.zip` pelo botão de download do GitHub e extraia a pasta do projeto.

Projeto-fonte Unity 6000.0.62f1 para Windows 64 bits, com seis naves e modelos originais Blender. Inclui instruções de abertura e build no README dentro do ZIP.

Validação disponível: 23 testes de domínio aprovados e 14 modelos FBX validados. A execução no Unity e o build Windows ainda precisam de validação em um Editor ativado; o arquivo não contém um executável compilado.

Esta branch é dedicada à entrega do arquivo. O ZIP tem seu SHA-256 em `orbita-fronteira-mvp.zip.sha256`.
